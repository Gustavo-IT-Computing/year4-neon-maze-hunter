# Neon Maze Hunter

## Overview

Neon Maze Hunter is a Unity-based arcade game inspired by classic maze-chase games such as Pac-Man.

Players navigate a neon-themed maze while collecting items, avoiding enemies and achieving high scores.

## Features

- Maze navigation gameplay
- Enemy AI behaviour
- Score tracking
- Collectable items
- Multiple game mechanics
- Unity game engine implementation

## Technologies Used

- Unity
- C#
- Visual Studio

## Learning Outcomes

This project strengthened skills in:

- Game development
- Unity Engine
- C# programming
- Player movement systems
- Collision detection
- Game design principles
